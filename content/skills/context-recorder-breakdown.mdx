## What it does

I built [Context Recorder](/projects/context-recorder) to capture feedback while I use an app. I talk through what I see and press a hotkey to mark moments. The recording keeps the screen, the transcript, the marks, browser events, and saved copies of the pages.

This skill turns one of those sessions into work. One command builds an evidence pack. The agent fills it in. A second command checks that nothing was skipped.

## How it works

```bash
python3 recorder.py prep SESSION -o PACK   # about 10 seconds
# the agent fills every block in PACK/ledger.md
python3 recorder.py check PACK/ledger.md   # exit 0 = every block and every mark is covered
```

`prep` writes a ledger: the transcript in 45-second blocks with each mark inline, the image for each mark, the element I was hovering, and the dialogs and menus open on screen at that moment. It also finds the code for every label I pointed at.

The agent opens every image, writes one item per distinct comment, and maps each item to code.

## Output shapes

- An exhaustive feedback list: broken, polish, unfinished, stop doing, start doing, what worked.
- Fix now plus a future-ideas doc.
- Raw input for the [Software Design Sleuth](/skills/software-design-sleuth).
- One issue with annotated screenshots.

## It's working if

- `check` passes, so every comment I made shows up somewhere.
- Items point at code, not just at the screen.
