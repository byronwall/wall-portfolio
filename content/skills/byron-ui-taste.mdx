## What it does

Every rule in this skill is a correction I gave an agent more than once. Too much padding. Cards inside cards. A toast that pushes the page down. A pill on every row. Links that break across lines. Once I've said it twice, it goes in the file.

Other UI skills ([10x](/skills/10x), [100x](/skills/100x)) read it first. It shows up a lot.

## A few of the rules

- **Dense by default.** "Over-padded" and "too cardy" are my most common complaints. Tighten before you add.
- **Zero layout shift.** Results arriving, a toast, or a copy confirmation must not move other content.
- **Links are colored text.** Same weight as body text, no underline, one shared hover.
- **Show full text in lists.** Truncate only inline references, and back each one with a hover card that adds information.
- **Remove low-value things** instead of restyling them.
- **Diagrams** get soft, low-chroma fills, and saturated color only on the data.

*Signal rows, one of the patterns in the file. Each row is a label, a fixed-width mark, and one line of text. Clicking a row opens the full detail in a popover under it, so nothing on the page moves. Only misses and unsettled answers get color. The skill keeps these screenshots as its reference.*

## How it works

It is mostly a rule list, grouped by density, borders, layout stability, links, truncation, hierarchy, and controls. It also has a small control-states CSS layer to copy and an audit script that captures every control at rest, hover, focus, and pressed without changing any data.
