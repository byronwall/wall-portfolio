Draftably is a diagram tool built around one readable `.draft` file. An agent writes the file. `draftably open` serves an editor that watches it, redraws when the agent changes it, and saves my drags and edits back into the same text. The same file always compiles to the same picture, so an agent can check its work from the command line without a browser.

- Try it: `pnpm dlx draftably open`

## How it works

- **The file**: nodes, groups, edges and layout rules, one statement per line. Manual drags save as soft placement lines such as `near` and `stay`, so later agent edits don't strand them. `pin` is a separate, hard choice.
- **The loop**: the CLI watches the file and serves the viewer. Saves carry a revision, so a stale save is rejected rather than overwriting the agent's change. A broken file keeps the last valid drawing on screen and names the bad line.
- **Layout**: layout engines can be named per group in the file. Results from interactive tools such as Improve, the layout timeline and the brush save as positions.
- **Headless checks**: `draftably check` and `draftably inspect --svg` compile and render without a browser, using the same router and text measurements as the viewer.

## Highlights

- Five themes (Graphite, Fieldnotes, Signal, Mulberry, Midnight), with numeric shades held to contrast targets and custom `brand` colors defined in the file.
- Bundled fonts with stored width tables, so the compiler, the viewer and the CLI wrap text identically.
- `draftably skill install` adds an agent skill for the file format. CI fails syntax changes that don't update the skill.
