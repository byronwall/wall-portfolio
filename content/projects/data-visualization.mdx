Shifty was the time series analysis platform I built at Allison Transmission. Engineers used it to find events in their test files, compute values for every event, filter the results in linked charts, and open the raw signals behind a pattern. More than 100 engineers used it.

It was internal software, so there are no screenshots here. I wrote up how it was built, how it grew, and what I learned in [Building a time series data analysis platform](/blog/building-a-time-series-data-analysis-platform).

[explorEDA](/projects/exploreda) is my open-source, clean-sheet take on the same linked-chart idea. It shares no code with Shifty.
