Gunk Patrol is a small, touch-first Phaser game built around one readable loop: run through the green mess, leave a clean blue route, and catch the alligators that get in the way.

## The cleanup loop

Drag anywhere on the playfield to move. Walking over gunk cleans it automatically, so the route itself explains the goal. Reach 90% cleanup to finish an area, with five hearts to make mistakes recoverable.

## Three places to clean

The route moves through a swamp, a sewer or tunnel, and a city. Each area keeps the same movement and cleanup rules while changing the setting, obstacles, and visual rhythm.

## Built for replay

Deterministic seeds make a run repeatable. Start a new area for a fresh route, or replay the same seed to practice a path and compare the result.
