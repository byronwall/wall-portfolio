The first logo ideas for [explorEDA](https://exploreda.dev) looked like network diagrams. That shape did not match the way the workspace feels. It is built around charts, tables, and selecting data.

The new mark uses a three-by-three grid with one cell highlighted. The icon can work alone at favicon size. The wordmark stays separate, so the full name remains readable in the site header.

![The explorEDA grid icon above its wordmark](/images/projects/exploreda/logo-stacked.svg)

The assets are SVGs. [Logo Dodo](https://logododo.com) generated the starting concepts, and the grid direction became the final mark.
